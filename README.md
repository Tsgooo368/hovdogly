# Ховдоглы

Ховор хариултын монгол тоглоом. `public/` дотор тоглоом, `server.js` нь онооны самбар, онлайн тоглогч, AI шалгалтыг хариуцна. Гадны сан шаардлагагүй (Node 20+).

## Ажиллуулах
```
npm start
```

## Тохиргоо (орчны хувьсагч)
| Нэр | Утга |
|---|---|
| `AI_API_KEY` | OpenRouter (эсвэл OpenAI-тэй нийцтэй үйлчилгээ)-ийн түлхүүр. Байхгүй бол AI шалгалт унтарна. |
| `AI_MODEL` | Анхдагч: `google/gemma-3-27b-it:free` (үнэгүй, өдрийн хязгаартай). Жишээ нь `qwen/qwen3-32b`. |
| `AI_BASE_URL` | Анхдагч: `https://openrouter.ai/api/v1`. Groq: `https://api.groq.com/openai/v1`. |
| `DATA_DIR` | Өгөгдөл хадгалах хавтас (Railway volume, жишээ нь `/data`). |

Нэг хариултыг нэг л удаа AI-аар шалгаж, дүнг `DATA_DIR/state.json`-д хадгална.
